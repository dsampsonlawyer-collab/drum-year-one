# Drum Year One

A 12-month beginner drum program: 156 lessons, milestone tests, a rudiment trainer with a recording checker, and a metronome.

Progress is saved in your browser on each device.

## Use it
Open the GitHub Pages link on your phone, then Share > Add to Home Screen. It works offline after the first load.

## Update it
Edit the lesson files (`l1.js` to `l4b.js`) or `index.html` and commit. Pages redeploys in about a minute.
